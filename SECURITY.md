# Security policy

Security fixes target the current `main` branch while the project is
experimental.

Report vulnerabilities through GitHub private vulnerability reporting after
the repository is published. Include the affected revision, a minimal
reproduction, impact, and suggested mitigation. Do not attach private files or
disclose credentials or exploit details in a public issue.

If private reporting is unavailable, open a public issue without sensitive
details and ask the maintainer to establish a private contact channel.
